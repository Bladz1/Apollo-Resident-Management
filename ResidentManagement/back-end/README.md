**🚀 Toàn bộ stack công nghệ**

**🖥️ Frontend**

- **Next.js (TypeScript)**.

- **Tailwind CSS**.

---

**⚙️ Backend**

- **Spring Boot** → framework Java backend mạnh mẽ, chuẩn doanh nghiệp.
- **Spring Data JPA (Hibernate)** → ORM (Entity ↔ Database mapping).
- **Spring Security** → phân quyền, xác thực (JWT/OAuth2).
- **REST API** → giao tiếp với frontend.

---

**🗄️ Database**

- **MySQL**

---

**☁️ Deployment & DevOps**

- **Docker** → đóng gói app/backend/frontend/database thành container.
- **AWS EKS/ECS** → chạy và quản lý container trên cloud.
- **Nginx / API Gateway** → reverse proxy, load balancing.
- **GitHub Actions** → CI/CD (build → test → deploy tự động).

---

**🛠️ Infrastructure as Code (IaC)**

- **Terraform** → quản lý hạ tầng AWS bằng code.
- **Helm** (nếu dùng Kubernetes) → quản lý deployment chart.

---
